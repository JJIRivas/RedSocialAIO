Aplicacion basica para probar el display de diferentes redes sociales en una feed.

Actualmente solo sorporta Mastodon y Misskey, no tiene algunas funcionalidades basicas, pero se puede ver contenido, dar "likes" y "reblogs".

Requiere de una cuenta para la aplicacion que se gestionaba por Firebase, actualmente fuera de servicio.

Hecha para un proyecto universitario.
